# Bear Customization Game

## Overview

This build is an interactive game where players select a bear and personalize it with clothing and accessories.

## Core experience

- Choose a bear from a selection of available characters.
- Change the bear's clothes, such as tops, bottoms, shoes, and costumes.
- Add or remove accessories, such as hats, glasses, bags, and other items.
- Preview each change immediately on the selected bear.
- Save or confirm the finished look.

## Key design considerations

- Make the customization controls simple and playful.
- Keep clothing and accessories visually compatible with each bear.
- Clearly show which bear and items are currently selected.
- Support resetting the look or switching to another bear at any time.
